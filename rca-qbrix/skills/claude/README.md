# RCA Qbrix skills (Claude)

One directory per exported Claude skill. `SKILL.md` sits at the root of that directory. Supporting files stay beside it.

```text
rca-qbrix/skills/claude/<name>/
  SKILL.md
  ...
```

These are RCA Qbrix skills for post-spin work. The skills Claude Code loads while working in this repository are the shared catalog in `.cursor/skills/`, reached through `.claude/skills/`.
