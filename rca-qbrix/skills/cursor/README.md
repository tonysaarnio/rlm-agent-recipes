# RCA Qbrix skills (Cursor)

One directory per exported Cursor skill. `SKILL.md` sits at the root of that directory. Supporting files stay beside it.

```text
rca-qbrix/skills/cursor/<name>/
  SKILL.md
  ...
```

These are RCA Qbrix skills for post-spin work. The skills Cursor loads while working in this repository live in `.cursor/skills/`.
